✈️ Airline Operations & Delay Analytics Dashboard

📊 Overview

An interactive Tableau dashboard designed to analyze airline performance, flight delays, airport operations, and delayed routes.
The dashboard transforms flight data into meaningful insights through KPIs, trends, maps, and interactive filters.

🎯 Key Features

- ✈️ Total Flights & Delayed Flights
- ⏱️ Average Delay & Delay Rate
- 📊 Airline Performance Analysis
- 📈 Monthly Delay Trends
- 🗺️ Airport Performance Map
- 🛫 Flight Route Map
- 🚨 Top 10 Delayed Routes
- 🌦️ Weather Impact Analysis
- 📋 Detailed Flight Analysis

🛠️ Tools Used

- Tableau – Dashboard & Visualization
- Microsoft Excel – Data Cleaning & Preparation

💡 Key Insights

The dashboard helps identify:

- Airlines with higher/lower delay rates
- Airports with frequent delays
- Most delayed flight routes
- Monthly and seasonal delay patterns
- Major causes of flight delays
